# 설명 도식 설계표

글로 따라가기 어려운 관계 하나를 그림으로 대신 잡아 주는 자리다.
장식이 아니고 보상도 아니다. **본문이 이미 말한 것**만 그린다.

지금 만든 것은 둘이다. 나머지 노드는 아래 「어느 글에 그림이 필요한가」에
필요성과 형식만 적어 두었다. 전부에 그림을 채우는 것이 목표가 아니다.

문단 번호 `[n]` 은 [`essay-structure.md`](essay-structure.md) 와 같은 기준,
곧 P3-2 직전(`3f2a130`)의 `article.body` 첨자다.

## 공통 형식

| | |
|---|---|
| 방식 | 인라인 SVG. 외부 파일도, 라이브러리도, 네트워크 요청도 없다 |
| 틀 | `viewBox="0 0 200 140"` 둘. 두 칸의 자와 여백이 같아야 견줄 수 있다 |
| 라벨 | SVG 안에 굽지 않는다. 제목 · 설명 · 범례는 모두 HTML 글자다 |
| 배치 | 기본은 위아래. 560px 이상에서만 좌우 (앱 틀이 420px 이라 사실상 늘 위아래다) |
| 색 | `빛 #8a6d1f` · `물 #4f7080` · `흙 #7d7566` · `땅 표면 #55574f`. 모두 바탕과 3:1 이상 |
| 뜻을 나르는 것 | 화살표의 **방향**과 **라벨**. 색은 거들기만 한다 |
| 읽히는 이름 | `figure` + `figcaption`. SVG 는 `aria-hidden` 이고, 제목·설명·범례가 실제 글자로 그 옆에 있다 |

그림 자체를 읽어 주지 않는 대신, 그림을 빼고 글자만 읽어도 비교가 서게 썼다.
정적인 그림이라 초점도 버튼 역할도 주지 않았다.

# 1. 빛이 지나는 길 (`lightPath`)

**노드** `cloudWhite` — 구름은 왜 흰색으로 보일까?

### 읽는 사람이 잡아야 할 관계 하나

> 같은 물이라도 **한 덩어리로 있을 때와 수많은 작은 물방울로 흩어져 있을 때**
> 빛이 나가는 길이 달라진다.

### 근거가 되는 기존 문단

| | |
|---|---|
| `[1]` | 컵 속의 물은 투명하고, 하늘의 구름은 하얗습니다 |
| `[3]` | 답은 물의 색이 아니라 빛이 물방울을 만나는 방식에 있습니다 |
| `[5]` | 일부는 그대로 지나가고, 일부는 방향을 바꾸어 퍼집니다 — 이것이 산란 |
| `[17]` | 물방울 하나를 떼어놓으면 거의 투명합니다. 그런 물방울이 수없이 모여… |
| `[21]` | 컵 속에서는 투명했던 물이 하늘에서는 흰 구름이 되는 이유 |
| 나오는 문제 | 물방울을 모두 합쳐 한 덩어리로 만들면 흰색은 남지 않는다 (정답 B) |

### 그림에 들어간 것과 그 뜻

| 요소 | 뜻 |
|---|---|
| 왼쪽 칸의 그릇과 물 | 한 덩어리로 모인 물 |
| 그릇으로 들어가는 금색 선 | 들어오는 빛 한 줄기 |
| 수면에서 꺾이는 각 | 경계에서 방향이 바뀐다 |
| 수면에서 위로 갈라지는 가는 화살표 | 일부는 되비친다 |
| 그릇 아래로 빠져나가는 화살표 | 대체로 지나간다 |
| 오른쪽 칸의 파란 동그라미들 | 공기 중에 떠 있는 작은 물방울 |
| 방울마다 갈라지는 금색 선 | 만날 때마다 방향이 바뀐다 |
| 사방으로 — 되돌아 나오는 쪽까지 — 향한 화살촉 | 여러 방향으로 퍼진다 |

### 일부러 그리지 않은 것

- **파장에 따른 차이.** 레일리와 미 산란의 구분은 본문 `[6]`–`[14]` 의 몫으로 두었다.
  선을 무지개색으로 가르면 프리즘·무지개라는 다른 현상을 암시한다. 선은 한 색이다.
- **그릇의 벽에서 일어나는 굴절.** 유리를 한 겹 더 그리면 관계가 흐려진다.
- **각도의 크기.** 꺾이는 각은 눈에 보이라고 잡은 것이지 굴절률로 계산한 값이 아니다.
- **물방울의 수와 크기.** 구름의 실제 방울 수·지름과 아무 관계가 없다.

### 잘못 읽힐 수 있는 곳과 막는 방법

| 잘못 읽을 수 있는 것 | 막는 방법 |
|---|---|
| 컵 속의 물은 빛과 아무 일도 하지 않는다 | 수면에서 꺾는 각을 눈에 보이게 그리고, 되비치는 가는 화살표를 함께 둔다. 칸 설명도 “경계에서 방향이 꺾이고, 일부는 되비칩니다” 로 적는다 |
| 구름이 수증기(기체)다 | 오른쪽 칸의 제목이 “수많은 작은 물방울” 이고, 그린 것도 방울이다. 김·연기 모양을 쓰지 않는다 |
| 선의 개수가 빛의 양이다 | 작은 글씨로 “방울의 수와 크기, 선의 개수에는 뜻이 없습니다” |
| 빛이 색깔별로 갈라진다 | 선을 한 색으로만 쓴다 |

### 들어간 자리

`구름은 흰 물질이 아니다` 구간, `[17]`(물방울 하나를 떼어놓으면 거의 투명합니다)
바로 뒤. “수없이 모여” 를 읽은 자리에서 그 “수없이” 를 눈으로 본다.
도판(`plate: cloud`)은 글 맨 위에 그대로 있다. 도판은 구름 그 자체를 보여 주고,
이 도식은 두 조건을 견준다. 역할이 겹치지 않아 둘 다 둔다.

### 캡션

> 같은 빛이 들어와도, 물이 한 덩어리로 있을 때와 작은 물방울로 흩어져 있을 때
> 빛이 나가는 길이 달라집니다.

### 그림을 보지 않는 사람이 읽는 것

개념도 → 캡션 → “한 덩어리로 모인 물 / 빛은 대체로 지나갑니다. 경계에서 방향이
꺾이고, 일부는 되비칩니다.” → “수많은 작은 물방울 / 빛이 방울을 만날 때마다
방향을 바꾸어, 되돌아 나오는 쪽까지 여러 방향으로 퍼집니다.” → 범례 → 단서.
그림 없이 이 문장만으로 비교가 선다.

# 2. 물이 들어갈 길 (`waterWay`)

**노드** `waterInfiltration` — 왜 어떤 물은 땅속으로 스며들고 어떤 물은 흘러갈까?

### 읽는 사람이 잡아야 할 관계 하나

> 같은 비를 받아도, **표면에서 안쪽으로 이어지는 길이 있는가**에 따라
> 물이 들어가기도 하고 지표를 따라 흐르기도 한다.

### 근거가 되는 기존 문단

| | |
|---|---|
| `[8]` `[9]` | 공극은 서로 이어지면서 땅 안쪽으로 가는 길을 이룬다 |
| `[17]` | 큰 공극은 물이 빠르게 지나가기에 유리하다 |
| `[25]` | 들어오는 속도를 땅이 따라가지 못하면 물이 지표에 남는다 (침투초과 유출) |
| `[29]` | 눌린 땅에서는 공극이 찌그러진다. 토양 다짐은 침투를 줄일 수 있다 |
| `[30]` | 뿌리와 토양생물이 뚫은 굴은 대공극이 되어 빠르게 들어갈 길을 만든다 |
| `[31]` `[32]` | 같은 비를 맞고도 한쪽은 대부분 안으로, 다른 쪽은 대부분 표면 위로 |
| 들어가는 문제 | 말라 있어도 들어갈 통로가 부족하면 빠르게 받아들이지 못한다 (정답 B) |
| 나오는 문제 | 아래가 말라 있어도 표면에서 안쪽으로 이어지는 물길이 막히면 물이 위에 남는다 (정답 A) |

### 그림에 들어간 것과 그 뜻

| 요소 | 뜻 |
|---|---|
| 두 칸에 똑같이 그린 빗줄기 여섯 | 같은 비를 받는다 — 비교의 조건 |
| 가로 굵은 선 | 땅의 표면 |
| 왼쪽 칸, 표면 바로 아래의 납작한 타원 줄 | 눌려 찌그러진 공극 (원인) |
| 오른쪽 칸, 표면에서 아래로 이어진 굵은 곡선 | 뿌리가 남긴 자리와 토양생물의 굴 (원인) |
| 두 칸에 똑같이 그린 흙 알갱이와 둥근 빈 자리 | 아래의 사정은 같다 — 다른 것은 표면뿐 |
| 아래로 향한 파란 화살표 | 땅 안으로 들어간 물 |
| 옆으로 향한 파란 화살표 | 지표를 따라 흐른 물 |
| 점선 화살표 | 들어가다 멈춘 물 |
| 표면에 고인 파란 면 | 갈 곳을 찾지 못하고 남은 물 |

### 일부러 그리지 않은 것

- **포화초과 유출.** 본문 `[21]` 은 아래가 이미 물로 찬 경우도 다룬다.
  한 그림에 두 원인을 겹치면 “왜 흐르는가” 가 둘로 갈린다. 그림은 통로 쪽만 잡는다.
- **속도와 양.** 화살표의 수와 길이는 세는 값이 아니다.
- **깊이와 알갱이 크기.** 축척이 아니다.
- **물을 머금는 힘.** 작은 공극이 물을 붙잡는 이야기(`[18]`)는 글에 남겨 두었다.

### 잘못 읽힐 수 있는 곳과 막는 방법

| 잘못 읽을 수 있는 것 | 막는 방법 |
|---|---|
| 마른 흙은 잘 빨아들이고 젖은 흙은 못 빨아들인다 | 두 칸의 이름을 물기가 아니라 **표면의 상태**로 붙인다(“밟혀 다져진 표면” · “뿌리와 굴이 길을 이어 둔 표면”). 작은 글씨로 “젖었는지 말랐는지가 아니라, 길이 이어져 있는지를 견준 그림” 이라고 못 박는다 |
| 한쪽은 100% 침투, 다른 쪽은 100% 유출 | 다져진 쪽에도 들어가는 점선 화살표를 하나 두고, 이어진 쪽에도 표면에 남는 화살표와 고인 물을 둔다. 칸 설명도 “물은 위에 남아 흐를 수 **있습니다**”, “미처 들어가지 못한 물은 표면에 남습니다” 로 적는다 |
| 아래 흙에 빈 자리가 없어서 못 들어간다 | 두 칸의 아래쪽 빈 자리를 **같은 자리에 같은 수로** 그린다. 나오는 문제의 정답과 같은 그림이 된다 |
| 화살표 굵기가 유량이다 | 작은 글씨로 “화살표는 방향만 가리킵니다” |
| 단면이 실제 깊이다 | `개념도` 표시와 “깊이와 알갱이 크기는 실제 축척이 아닙니다” |

### 들어간 자리

`같은 흙이라도 상태가 달라지면 결과가 달라진다` 구간의 끝,
`[32]`(한쪽은 대부분을 땅 안으로…) 바로 뒤. 원인(`[29]` `[30]`)과 결과(`[31]` `[32]`)를
막 읽은 자리에서 그 둘을 한 화면에 본다. 다음 구간 `물은 같았다` 로 넘어가기 직전이다.

이 글에는 맨 위 도판이 없다. `plate: 'soil'` 은 아직 그릴 것이 없어
`plate()` 가 빈 문자열을 돌려주기 때문이다. 이 도식이 그 자리를 대신하는 것은
아니다. 그림 파일이 올라오면 도판은 도판대로 글 맨 위에 선다.

### 캡션

> 같은 비를 받아도, 표면에서 안쪽으로 이어지는 길이 있는 쪽이 물을 더 받아들입니다.

### 그림을 보지 않는 사람이 읽는 것

개념도 → 캡션 → “밟혀 다져진 표면 / 표면의 공극이 눌려 납작해지면 안쪽으로 가는
길이 좁아지거나 끊깁니다. 아래에 빈 자리가 남아 있어도 물은 위에 남아 흐를 수
있습니다.” → “뿌리와 굴이 길을 이어 둔 표면 / 큰 통로가 표면에서 안쪽까지 이어져
물이 빠르게 들어갈 수 있습니다. 그래도 미처 들어가지 못한 물은 표면에 남습니다.”
→ 범례(화살표의 방향이 뜻하는 것, 두 칸에서 같게 둔 것) → 단서.

# 어느 글에 그림이 필요한가

열한 편을 모두 보고 적었다. 이번에는 위의 둘만 만들었다.
필요성이 높다고 적은 것이 곧 다음에 만든다는 뜻은 아니다.

| 글 | 필요성 | 형식 | 그림이 잡아 줄 관계 | 글보다 나은 이유 | 만들기 전에 확인할 위험 |
|---|---|---|---|---|---|
| **cloudWhite** | — | 비교 | **만들었다** (`lightPath`) | | |
| rainStart | 높음 | 비교 | 크기가 고른 구름과 일부가 커진 구름 — 크기 차이가 낙하 속도 차이를 낳고, 충돌·병합으로 이어진다 | 「크기가 벌어지면 성장이 빨라진다」는 되먹임은 문장으로는 한 번에 서지 않는다. 나오는 문제가 바로 이 비교다 | 방울 크기를 잰 값처럼 보이게 하지 말 것. “무거워져서 떨어진다” 는 그림이 되지 않게 할 것(본문 `[33]` 이 명시적으로 부정한다). 베르게론 과정은 접힘으로 내려 둔 대목이라 그림으로 끌어올리지 말 것 |
| **waterInfiltration** | — | 비교 | **만들었다** (`waterWay`) | | |
| waterLatentHeat | 높음 | 흐름 | 증발에서 나간 에너지가 수증기를 따라 올라가 응결에서 대기로 건네지는 한 바퀴 | 에너지가 “어디서 나가 어디로 들어오는지” 는 여섯 구간에 흩어져 있다. 한 줄기로 세우면 잡힌다 | 열을 주머니에 담긴 물건처럼 그리지 말 것 — 본문 `[4]` 가 정면으로 부정한다. 수증기를 흰 김으로 그리지 말 것. 온도·열량 수치를 붙이지 말 것 |
| seedWater | 중간 | 단계 | 흡윤 → 대사 재개 → 발아, 그리고 물 말고도 걸린 조건들 | 이미 소제목 일곱이 단계를 잘 나눠 둔 글이다. 그림이 더할 것은 “물만으로는 아니다” 한 가지뿐 | 단계가 정해진 시간표처럼 보이지 않게 할 것. 물만 닿으면 깨어난다는 그림이 되지 않게 할 것(들어가는 문제와 충돌한다) |
| plantGrowth | 높음 | 비교 | 몸의 재료(공기 중 이산화탄소) · 에너지(빛) · 흙이 주는 것(무기질)이 서로 다른 갈래라는 것 | 들어가는 문제가 정확히 이것을 묻는다. 「에너지와 물질은 다르다」 는 글로는 가장 자주 미끄러지는 대목이다 | 흙의 몫을 0 처럼 그리지 말 것. 광합성 화학식이나 비율 수치를 붙이지 말 것. 물이 재료이자 전달자이자 조건이라는 여러 역할(`[41]`–`[47]`)을 하나로 줄이지 말 것 |
| treeForm | 중간 | 흐름 | 생장점에서 같은 결정이 되풀이되며 형태가 쌓인다 — 도면이 아니라 기록 | 「미리 들어 있지 않다」 를 그림으로 보이기는 어렵지만, 되풀이되는 과정은 그릴 수 있다 | 나무의 완성된 모양을 크게 그리면 본문의 결론과 정반대가 된다. 설계도처럼 보이는 어떤 표현도 쓰지 말 것 |
